### O Operador Ternário (condicao ? verdadeiro : falso)

É o formato mais utilizado no dia a dia do React para alternar entre dois blocos visuais de acordo com o estado.

```jsx
import { useState } from 'react';

function StatusLogin() {
  const [estaLogado, setEstaLogado] = useState(false);

  return (
    <div style={{ padding: '20px' }}>
      {/* Usamos o operador ternário dentro do JSX */}
      {estaLogado ? (
        <h2>Bem-vindo de volta, usuário!</h2>
      ) : (
        <h2>Por favor, faça login para continuar.</h2>
      )}
      <button onClick={() => setEstaLogado(!estaLogado)}>
        {estaLogado ? 'Sair' : 'Entrar'}
      </button>
    </div>
  );
}

export default StatusLogin;
```

### O Operador Lógico && (E Curto-Circuito)

Quando você quer exibir um elemento apenas se uma condição for verdadeira (e não quer renderizar nada caso seja falsa), o operador `&&` é a escolha perfeita.

```jsx
function Notificacao({ temMensagens }) {
  return (
    <div>
      <h3>Painel Principal</h3>
      {/* Se temMensagens for true, o alerta é exibido. Se for false, o React ignora. */}
      {temMensagens && (
        <p style={{ color: 'red' }}>Você tem novas mensagens não lidas!</p>
      )}
    </div>
  );
}
```

## Renderização de Listas: O Método .map()

Muitas vezes, não temos apenas um item fixo para exibir, mas sim uma lista de dados vinda de um banco de dados ou API (como uma lista de produtos de um e-commerce, tarefas de uma lista de afazeres ou um ranking de pontuação).

Em JavaScript, transformamos arrays utilizando o método `map()`. No React, fazemos exatamente a mesma coisa para transformar um array de dados em um array de componentes JSX.

Exemplo prático: Renderizando uma lista de tarefas

```jsx
function ListaTarefas() {
  const tarefas = [
    { id: 1, texto: 'Estudar fundamentos do React' },
    { id: 2, texto: 'Praticar hooks (useState)' },
    { id: 3, texto: 'Criar aplicação frontend' }
  ];

  return (
    <div style={{ padding: '20px' }}>
      <h2>Minha Lista de Tarefas</h2>
      <ul>
        {/* O .map percorre o array e retorna um elemento <li> para cada item */}
        {tarefas.map((tarefa) => (
          <li key={tarefa.id}>{tarefa.texto}</li>
        ))}
      </ul>
    </div>
  );
}

export default ListaTarefas;
```

### A Importância Crítica da Propriedade key

Se você reparar no exemplo acima, a tag `<li>` possui um atributo chamado `key`:

```jsx
<li key={tarefa.id}>{tarefa.texto}</li>
```

- **O que é a `key`?** É uma identificação única que o React exige sempre que você renderiza uma lista de elementos.
- **Por que ela é obrigatória?** Quando um item da lista é adicionado, removido ou reordenado, o React usa a `key` para rastrear exatamente qual elemento mudou, atualizando o Virtual DOM de forma extremamente eficiente sem precisar recriar a lista inteira do zero.
- **Boa prática:** Sempre utilize um identificador único vindo dos seus dados (como `id_usuario`, `id_produto`). Evite usar o índice do array (`index`) como chave, pois isso pode causar bugs visuais graves se a ordem da lista mudar.

## Manipulação de Formulários - Capturando e Controlando a Entrada do Usuário

Nos capítulos anteriores, aprendemos a estruturar componentes (Capítulo 1), passar dados via Props (Capítulo 2), gerenciar a memória com o Estado usando o `useState` (Capítulo 3) e controlar o que aparece na tela através de renderização condicional e listas (Capítulo 4).

Agora, vamos dar um passo fundamental para qualquer aplicação interativa: como coletar dados digitados pelos usuários através de formulários e inputs.

### O Conceito de Inputs Controlados

No HTML tradicional, os elementos de formulário (como `<input>`, `<select>`, `<textarea>`) mantêm o seu próprio estado internamente no navegador. Se você digita algo em um input, o próprio navegador gerencia aquele texto.

No React, mudamos essa lógica para garantir o controle total dos dados. Adotamos o padrão de Inputs Controlados:

- O valor exibido no input é ditado estritamente por uma variável de Estado (`useState`).
- Sempre que o usuário digita algo, dispararmos uma função que atualiza esse estado imediatamente.
- Dessa forma, o componente React é a "única fonte da verdade" para o valor daquele campo.

### Construindo um Formulário Controlado na Prática

Vamos criar um componente de cadastro simples onde o usuário digita seu nome e e-mail, e esses dados são capturados e exibidos quando o formulário é enviado.

```jsx
import { useState } from 'react';

function FormularioCadastro() {
  // Criamos estados separados para cada campo do formulário
  const [nome, setNome] = useState('');
  const [email, setEmail] = useState('');

  // Função disparada quando o formulário é submetido
  function handleSubmit(evento) {
    // Previne o comportamento padrão do navegador de recarregar a página inteira
    evento.preventDefault();

    console.log('Dados submetidos:', { nome, email });
    alert(`Usuário cadastrado: ${nome} (${email})`);

    // Opcional: limpar os campos após o envio
    setNome('');
    setEmail('');
  }

  return (
    <form onSubmit={handleSubmit} style={{ padding: '20px', maxWidth: '300px' }}>
      <h2>Cadastro de Usuário</h2>

      <div style={{ marginBottom: '15px' }}>
        <label>Nome: </label>
        <br />
        <input
          type="text"
          value={nome} // O valor do input é amarrado ao estado
          onChange={(e) => setNome(e.target.value)} // Atualiza o estado a cada tecla digitada
          placeholder="Digite seu nome"
          style={{ width: '100%', padding: '8px', boxSizing: 'border-box' }}
        />
      </div>

      <div style={{ marginBottom: '15px' }}>
        <label>E-mail:</label>
        <br />
        <input
          type="email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          placeholder="Digite seu e-mail"
          style={{ width: '100%', padding: '8px', boxSizing: 'border-box' }}
        />
      </div>

      <button type="submit" style={{ padding: '10px 15px', cursor: 'pointer' }}>
        Cadastrar
      </button>
    </form>
  );
}

export default FormularioCadastro;
```

Detalhes cruciais deste código:

- `value={nome}`: Garante que o input reflita exatamente o que está guardado no estado.
- `onChange={(e) => setNome(e.target.value)}`: O evento `onChange` captura cada alteração. `e.target.value` extrai o texto que acabou de ser digitado e atualiza o estado instantaneamente.
- `evento.preventDefault()`: No evento de envio (`onSubmit`), essa linha impede que o navegador recarregue a página (comportamento nativo do HTML), permitindo que o React processe os dados de forma assíncrona (ótimo para enviar depois via API para o nosso backend em Node.js!).

## Lendo Múltiplos Inputs com um Único Estado (Avançado)

Se o seu formulário tiver 10 ou 15 campos diferentes, criar um `useState` para cada um deles (nome, email, telefone, endereco, etc.) pode deixar o código verboso.

Uma prática muito comum e elegante é agrupar todos os campos em um único objeto de estado:

```jsx
import { useState } from 'react';

function FormularioCompleto() {
  // O estado agora é um objeto contendo todas as propriedades do formulário
  const [formulario, setFormulario] = useState({
    nome: '',
    email: '',
    cidade: ''
  });

  function handleChange(evento) {
    const { name, value } = evento.target;

    // Atualizamos apenas a propriedade correspondente usando a sintaxe de espalhamento (...)
    setFormulario(estadoAnterior => ({
      ...estadoAnterior,
      [name]: value
    }));
  }

  function handleSubmit(e) {
    e.preventDefault();
    console.log('Formulário enviado:', formulario);
  }

  return (
    <form onSubmit={handleSubmit} style={{ padding: '20px' }}>
      <input
        type="text"
        name="nome"
        value={formulario.nome}
        onChange={handleChange}
        placeholder="Nome"
      />
      <br /><br />
      <input
        type="email"
        name="email"
        value={formulario.email}
        onChange={handleChange}
        placeholder="E-mail"
      />
      <br /><br />
      <input
        type="text"
        name="cidade"
        value={formulario.cidade}
        onChange={handleChange}
        placeholder="Cidade"
      />
      <br /><br />
      <button type="submit">Enviar</button>
    </form>
  );
}

export default FormularioCompleto;
```

- **O operador de espalhamento (`...estadoAnterior`):** Garante que, ao alterarmos o campo `nome`, os campos `email` e `cidade` não sejam apagados, preservando o restante do objeto de estado.
- **A propriedade `name`:** Serve como chave dinâmica (`[name]: value`) para identificar qual campo específico está sendo alterado na função `handleChange`.
