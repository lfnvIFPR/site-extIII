## Como funciona um código?

Um programa é um conjunto de instruções binárias que o computador executa para realizar tarefas. As Linguagens de programação são responsáveis por fazerem a tradução da nossa escrita semântica para o binário do computador.

Para escrever o código, utilizaremos o Visual Studio Code(VS Code), um editor que oferece recursos para facilitar a organização dos arquivos.

### Instalando o VS Code

1. Acesse o site oficial: https://code.visualstudio.com/
2. Baixe a versão referente ao seu sistema operacional (Windows, macOS ou Linux).
3. Execute o instalador e siga as instruções apresentadas.
4. Abra o VS Code e crie uma pasta chamada `meu-primeiro-projeto-web`.
