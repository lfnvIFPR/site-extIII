# useEffect

## Comunicação Assíncrona e Efeitos Colaterais - Conectando o React ao Mundo Externo

Nos capítulos anteriores, aprendemos a estruturar componentes (Capítulo 1), passar dados via Props (Capítulo 2), gerenciar o estado local com o `useState` (Capítulo 3), controlar a renderização e listas (Capítulo 4) e capturar entradas de usuários através de formulários (Capítulo 5).

Até agora, todo o funcionamento das nossas aplicações React era puramente interno (estava na memória do navegador). Mas como um frontend exibe produtos vindos de um banco de dados, lista usuários cadastrados ou envia um formulário para uma API Node.js?

É exatamente isso que vamos resolver neste capítulo explorando a comunicação assíncrona e o Hook `useEffect`.

### O Conceito de Efeitos Colaterais (Side Effects) e o useEffect

Em um componente React, a função principal de renderização deve ser "pura": ela recebe props e estado e retorna JSX. No entanto, tarefas como buscar dados de uma API, alterar o título da aba do navegador, interagir com o `localStorage` ou configurar um timer não fazem parte estritamente da renderização visual. Elas são chamadas de Efeitos Colaterais (Side Effects).

Para executar esses efeitos no momento correto do ciclo de vida de um componente, utilizamos o Hook `useEffect`.

A estrutura básica do `useEffect`:

```jsx
import { useEffect, useState } from 'react';

function MeuComponente() {
  useEffect(() => {
    // Código do efeito colateral é executado aqui
    console.log('O componente apareceu na tela!');
  }, []); // Array de dependências
}
```

O segredo do Array de Dependências (`[]`):

O segundo argumento do `useEffect` é um array que controla quando o efeito deve ser executado:

- **Array vazio (`[]`):** O código de dentro do efeito roda apenas uma vez, exatamente quando o componente é montado (aparece pela primeira vez na tela). É o local perfeito para buscar dados iniciais de uma API.
- **Array com variáveis (`[idUsuario]`):** O código roda na montagem e sempre que a variável dentro do array mudar de valor.
- **Sem array:** O efeito roda a cada ciclo de re-renderização do componente (geralmente evitado para prevenir loops infinitos).

### Buscando Dados de uma API (Fetch API ou Axios)

Para se comunicar com um servidor externo ou com a nossa própria API em Node.js, utilizamos funções assíncronas do JavaScript (`async`/`await`) combinadas com o método nativo `fetch` (ou bibliotecas como o `axios`).

Vamos construir um componente que busca uma lista de usuários de uma API pública e os exibe na tela:

```jsx
import { useState, useEffect } from 'react';

function ListaUsuariosAPI() {
  const [usuarios, setUsuarios] = useState([]);
  const [carregando, setCarregando] = useState(true);

  // useEffect para buscar os dados assim que o componente carregar
  useEffect(() => {
    async function buscarDados() {
      try {
        const resposta = await fetch('[https://jsonplaceholder.typicode.com/users](https://jsonplaceholder.typicode.com/users)');
        const dados = resposta.json(); // Converte o retorno para JSON
        setUsuarios(dados); // Atualiza o estado com os dados da API
      } catch (erro) {
        console.error('Erro ao buscar usuários:', erro);
      } finally {
        setCarregando(false); // Desativa o indicador de carregamento independentemente do sucesso ou erro
      }
    }

    buscarDados();
  }, []); // Array vazio garante que a requisição ocorra apenas uma vez na montagem

  return (
    <div style={{ padding: '20px' }}>
      <h2>Usuários Buscados da API</h2>
      {/* Renderização condicional para o estado de carregamento */}
      {carregando ? (
        <p>Carregando dados do servidor...</p>
      ) : (
        <ul>
          {usuarios.map((usuario) => (
            <li key={usuario.id}>
              <strong>{usuario.name}</strong> ({usuario.email})
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}

export default ListaUsuariosAPI;
```

### O Ciclo de Vida da Requisição Assíncrona

Quando criamos aplicações que conversam com o backend, lidamos com três estados fundamentais na interface:

- **O Estado Inicial (Carregamento / Loading):** O usuário abre a página, o `useEffect` dispara a requisição e a tela exibe um aviso de carregamento (`carregando = true`).
- **O Sucesso (Dados Prontos):** A API responde com os dados, o estado é atualizado (`setUsuarios(dados)`), o carregamento é encerrado (`setCarregando(false)`), e o React redesenha a lista na tela.
- **A Falha (Tratamento de Erro):** Se a rede cair ou o servidor falhar, o bloco `catch` captura o erro e impede que a aplicação quebre, permitindo exibir uma mensagem amigável ao usuário.
